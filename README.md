# Beginner Portfolio

This is a simple personal portfolio website created while learning:

- HTML
- CSS
- Bootstrap
- Tailwind CSS

## Files

```text
portfolio/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## How to Run

Just open `index.html` in a web browser.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Tailwind CSS

## GitHub

Create a GitHub repository and upload the project files.

For GitHub Pages:

1. Open the repository.
2. Go to Settings.
3. Select Pages.
4. Select the `main` branch.
5. Select the root folder.
6. Save.
